# dsh-xiangqi 使用手册

这份手册分两部分：**人类**怎么在浏览器里下棋，**agent** 怎么用工具应战。看完能自己开一局、走完、导出记谱，并把链接发给别人或 agent。

---

## 一、人类：怎么下棋

### 1. 拿到邀请链接

在 DSH 里让 agent 开一局，例如：

> 开一局象棋，我执红，20 分钟。

agent 会调用 `xiangqi_new_game`，回复里带一条邀请链接，形如：

```text
http://127.0.0.1:5000/?k=<token>
```

- `?k=` 后面是这一局的**口令**，18 位、只对本局有效。
- 链接就是门票：**谁拿到链接谁就能走子**，别发到公开群。
- 链接里已经有口令，页面本身不会显示口令，也不会把口令写进棋谱或日志。

用手机或电脑浏览器打开链接即可，不需要装任何东西。

### 2. 看状态条

页面顶部（手机在最上面，桌面在右侧信息栏）显示两样东西：

- **该谁走**：`红方走棋` / `黑方走棋`；如果轮到你，旁边会有「你」标记。红点=红方，黑点=黑方。
- **剩余时间**：`mm:ss` 倒计时。全局限时默认 20 分钟，**第一手落子才开始计时**；剩余 ≤ 60 秒时数字变红并闪烁。

### 3. 走子

1. 点**自己的**一枚棋子：棋子会浮起高亮，棋盘上出现合法落点提示——**绿色圆点**是空位，**红色圆圈**是可以吃的对方棋子。
2. 点一个高亮落点：落子，棋谱自动追加一手。
3. 点空白处或再点一次可取消选择。

规则全部由服务端判定，前端只负责展示：

- 非法走子会弹出**服务端返回的人话原因**（例如「炮吃子必须隔一个棋子」），同时棋子抖动回弹，选中不会丢，可以改点别的落点。
- 还没轮到你时点自己的子，会提示等待对方（agent）落子。

### 4. 看棋谱

页面底部（桌面在右侧）是棋谱，按回合两列排列：

```text
1. 炮二平五    马8进7
2. 马二进三    车9平8
```

- 每走一手自动追加并**滚动到最新**，最近一手会高亮。
- 右侧（桌面在标题旁）显示总手数。
- 点「记谱」可以下载本局 `.md` 文件（中文记谱 + ICCS + FEN + 文字棋盘）。

### 5. 控制按钮

| 按钮 | 作用 |
| --- | --- |
| 新局 | 结束当前局、生成新口令与新链接。旧口令立即失效，旧记谱作废 |
| 悔棋 | 请服务端撤销最近一手；能不能悔由服务端决定，失败会显示原因 |
| 认输 | 二次确认后本局判负 |
| 记谱 | 下载 Markdown 记谱 |
| 🔊 / 🔇 | 音效开关（默认开，选择记在浏览器 localStorage） |

> 网页上**没有**「穿透」按钮和穿透面板（0.2.0 起移除）：需要公网地址时，直接让 agent 执行 `xiangqi_tunnel start`，它会把链接发你。

### 5.1 音效

落子有清脆的木头声，且**能听出是谁在走**：

| 事件 | 音色 |
| --- | --- |
| 你落子 | 清脆的木质「嗒」+ 高频「啪」，稍低一点 |
| agent 落子 | 同样清脆、更亮更高一点 |
| 吃子 | 额外一声高频脆裂 |
| 将军 / 将军抽车 / 将死 | 两声短促高音提示 |
| 对局结束 | 赢：上行三音；输：下行三音 |

音效用 Web Audio 实时合成（不下载任何音频文件）。浏览器要求先有一次点击/按键才能出声，所以**第一次进入页面后点一下棋盘或按钮**即可解锁。点 🔇 关闭后不会再响，刷新仍记住。

### 5.2 招数提示

每一手都会带上战术标签（棋谱里是彩色小徽标，将军类会额外弹提示 + 提示音）：

| 标签 | 含义 |
| --- | --- |
| `将军` | 这一手正在将对方 |
| `双将` | 两枚棋子同时将军 |
| `将军抽车` / `将军抽子` | 将军的同时还捉住对方的车/炮马 |
| `将死` | 这一手直接绝杀 |
| `吃车` `吃马` `吃炮` `吃象` `吃士` `吃兵` | 吃了什么子 |
| `捉双` | 一枚棋子同时捉两枚以上大子 |
| `应将` | 这一手是在解自己的将 |
| `兵过河` / `卒过河` | 兵/卒刚过河 |

这些标签由规则层计算，网页、agent 工具输出、Markdown 记谱三处一致。

### 5.3 拿起放下动画

- **拿起**：点自己的棋子，棋子会抬高、放大并出现光晕（表示已拿在手里），同时显示可落点；
- **落下**：落子后棋子从出发格平移到目标格，再轻轻回弹落定；
- 系统开启「减少动态效果」时动画自动降级，不影响使用。

### 5.4 页面怎么更新（0.2.0 起）

不再用 SSE，也不再「先渲染再补拉」：页面用长轮询 `GET /api/wait?since=<当前rev>`，服务端挂起最多 25 秒，**局面一变立刻回包**，一次带回棋盘 + 合法落点 + 棋谱，原子更新。手机网络、公网隧道下都比原来的 SSE 稳。

对局结束后会弹出覆盖层，显示**谁赢**与**原因**（将死 / 超时 / 认输 / 和棋），可直接点「再来一局」，或点「看棋盘」关掉覆盖层复盘。

### 6. 开内网穿透，把链接发给别人

默认对弈服务只监听本机（`127.0.0.1`），手机不在同一台机器上就打不开。**网页上没有穿透按钮**（0.2.0 起移除），统一让 agent 开：

> 开一下内网穿透，把公网链接给我。

agent 调 `xiangqi_tunnel start`，返回公网 URL；把「公网地址 + `/?k=<token>`」拼成完整链接发给别人即可。要关闭就说「关掉穿透」（`xiangqi_tunnel stop`）。

两种提供方：

- `cloudflared`：默认，免配置，每次启动地址都会变。
- `natfrp`（SakuraFrp）：需要本机配置访问密钥与隧道 ID；没配置时启动会报错并提示改用 cloudflared。

关闭只结束插件自己拉起的隧道进程；网页关掉不影响对局。

### 7. 把链接发给 agent

agent 和你在同一局里，但**各走各的**：

- 你走完，agent 用 `xiangqi_wait` 等到局面变化，再决定怎么应。
- 想催 agent：直接对它说「该你了」。
- 想让 agent 复盘：对它说「把棋谱发我」，它调 `xiangqi_record` 返回 Markdown。
- 想看局面：对它说「现在什么局面」，它调 `xiangqi_board`。

注意：agent 用的是**同一份内存棋局**，不需要你把链接再发给它；链接只给人类浏览器用。

### 8. 口令规则（重要）

- **18 位**随机串，字符集 `[a-z0-9]`。
- **单局有效**：只对生成它的那一局有效。
- **用完即弃**：点「新局」或 agent 重新 `xiangqi_new_game` 后，旧口令立即失效。
- 服务端只保存口令的 **SHA-256 摘要**用于校验，明文只在创建时返回给 agent。
- 页面不显示口令；前端从 URL 读取一次后只放进 `x-xiangqi-token` 请求头，后续请求不再拼 URL。
- 记谱、日志、导出的 `.md` 里口令一律写成 `<token>` 占位。

### 9. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 打开就显示「口令无效或已过期」 | 口令错了、过期了，或这一局已被新局替换。让 agent 重新 `xiangqi_new_game` 给新链接 |
| 页面提示「需要 JavaScript」 | 浏览器禁用了 JS。本页依赖 JS 拉棋局与长轮询更新，请在设置里启用后刷新 |
| 顶部一直「正在连接…」 | 对弈服务没起来或端口被占。让 agent 用 `xiangqi_status` 查站点地址，必要时重启 DSH |
| 走子没反应 / 提示网络异常 | 本机服务断开。0.2.0 起用长轮询，断线按 400ms→4s 退避自动重连；恢复后立即同步 |
| 时间到了还在走 | 超时由服务端判负并广播结束态，覆盖层出现后本局即结束 |
| 隧道一直「启动中」或变红 | cloudflared 没装 / 网络不通 / 需要代理。让 agent 用 `xiangqi_tunnel status` 看错误原因，或改用 natfrp（需先配置） |
| 公网地址返回 Cloudflare **502 Bad Gateway**，本机却正常 | 隧道端口与站点端口不一致（常见：站点在 61350，隧道却指向 5000）。调 `xiangqi_status` 对比「站点地址端口」和隧道「本地端口」；升级到 0.1.1 并重启 DSH，再 `xiangqi_tunnel stop/start`。**不要**手动起 cloudflared 绕过插件（status 看不到、stop 杀不掉） |
| 打开链接是 530 / 1033 之类的边缘错误 | 隧道进程已经死了（quick tunnel 域名随之失效）。`xiangqi_tunnel start` 重新开，并把新地址发给对方 |
| 手机打不开 `127.0.0.1` 链接 | 那是本机地址。先让 agent `xiangqi_tunnel start` 开穿透，再用公网地址 + `/?k=<token>` 访问 |
| 页面内容不跟着 agent 的走子更新 | 0.2.0 起统一用长轮询，正常几百毫秒内就会变。若长时间不动：先按 F5；仍不动就检查手机网络，或让 agent `xiangqi_status` 确认服务还在 |
| agent 换了一局，我这页就不刷新了 | 0.1.2 起页面会拿到 `xq_sid` 会话 cookie，换局只作废旧口令，同一浏览器会自动跟随新局；仍是老页面就按一次 F5，或直接用 agent 发的新链接 |
| 前端点「穿透 / 开启」报错 `隧道进程已退出（code=1）` | **0.2.0 起网页已移除穿透按钮**，请让 agent 操作。历史原因：cloudflared 的 metrics 端口 20241 被历史进程占用（0.1.2 起已改成 20500-20600 自动挑口） |
| 穿透显示 running，但给的地址是 `api.trycloudflare.com` 之类打不开 | 0.1.3 起已修：只接受真正的 quick tunnel 域名，排除 api/developers/help 等 API 与文档端点。升级重启后重开隧道即可；新域名 DNS 生效要等十几秒 |

## 二、agent：怎么用工具

agent 通过 7 个固定名字的工具操作同一份棋局，不需要也不应该自己实现规则。

| 工具 | 典型用法 |
| --- | --- |
| `xiangqi_new_game` | `{ humanSide: 'red', minutes: 20 }` → 返回邀请 URL 与先手方 |
| `xiangqi_board` | 无参数 → 文字棋盘、FEN、轮到谁、剩余时间、最近一手、棋谱 |
| `xiangqi_move` | `{ move: 'h2e2' }` 或 `{ move: '炮二平五' }`；非法返回人话原因（不抛栈） |
| `xiangqi_wait` | `{ timeoutMs: 60000, sinceRev: 12 }` → 等到人类走子或超时 |
| `xiangqi_record` | 无参数 → Markdown 记谱全文，并落盘 `games/<gameId>.md` |
| `xiangqi_tunnel` | `{ action: 'start', provider: 'cloudflared' }` → 公网 URL；`stop` 关闭 |
| `xiangqi_status` | 无参数 → 站点地址、口令是否就绪、隧道状态、剩余时间 |

推荐节奏：

1. 人类说「开一局」→ `xiangqi_new_game`，把链接给人类，并说明谁先走。
2. 轮到 agent → `xiangqi_board` 看局面，想好着法后 `xiangqi_move`。
3. 轮到人类 → **等自动唤醒**（人类落子后插件会给你发一条「[象棋自动唤醒] 对手刚走 …，现在轮到你」，直接 `xiangqi_board` + `xiangqi_move` 即可）；如果没收到，再用 `xiangqi_wait` 长等或让人类喊一声。
4. 人类要复盘 → `xiangqi_record`，把 Markdown 直接贴回去（里面没有口令明文）。
5. 人类要远程下 → `xiangqi_tunnel start`，把公网 URL 拼上 `/?k=<token>` 发给人类；结束后 `xiangqi_tunnel stop`。

### 自动唤醒（默认开启）

人类每次在网页落子，插件会**主动**给发起对局的会话补一条用户消息（形如 `[象棋自动唤醒] 对手刚走 兵三进一（g3g4），现在轮到你（黑方）`）。所以 agent 不需要一直轮询：收到这条消息就查局面、应手即可。

- 关闭方式：配置 `"autoWake": false` 或环境变量 `XQ_AUTO_WAKE=0`；
- 前提：这一局必须是由 agent 用 `xiangqi_new_game` 建的（插件要记住会话）；如果对局是别处起的，插件没绑定会话，只能靠 `xiangqi_wait` / 人类提醒；
- 唤醒消息会出现在对话里，属正常现象（就是让你知道该走棋了），文案不含口令。

注意事项：

- 走子格式三选一：ICCS（`h2e2`）、带横线（`h2-e2`）、中文记谱（`炮二平五`）。
- 非法走子工具会返回原因，不要重试同一手；先 `xiangqi_board` 看清局面。
- `xiangqi_wait` 上限 120000ms，超时会返回当前局面而不是报错。
- 新局会作废旧口令：人类还在用旧链接时不要擅自 `xiangqi_new_game`。
- 隧道公网地址每次启动都会变；复制给人类时用最新返回值。

## 三、一局完整示例

```text
人类：开一局象棋，我执红。
agent：xiangqi_new_game({ humanSide: 'red' })
       → 邀请链接 http://127.0.0.1:5000/?k=<token>，红方（你）先走。

人类：（打开链接，炮二平五）
agent：xiangqi_wait({ timeoutMs: 60000 })
       → 人类走 炮二平五（h2e2），轮到黑方
       xiangqi_move({ move: '马8进7' })

人类：（马二进三）
agent：xiangqi_wait() → 新局面
       xiangqi_move({ move: '车9平8' })

人类：开个穿透，我把链接发给同事看。
agent：xiangqi_tunnel({ action: 'start' })
       → https://example.trycloudflare.com

人类：这局认输了，把棋谱发我。
agent：xiangqi_record() → Markdown 记谱（含口令占位）
       xiangqi_tunnel({ action: 'stop' })
```
